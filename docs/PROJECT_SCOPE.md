# MSS AI Offline Translator — v1.1 Scope

Complete branded Flutter UI with functional integration points for native llama.cpp GGUF inference and download/import. Offline translation between Pashto, Dari, English, German. Writing modes: paragraph, email, improve, summarize; private chat, persisted library; low-memory mode.

Model weights downloaded separately (~563 MB). Native compatibility/performance must be validated on Android device. No online inference backend, no fake ChatGPT responses, no paid API.
